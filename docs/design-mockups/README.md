## Token extract

- Sans: Inter
- Display: Playfair Display
- Gray scale: 50 `#fafafa` … 950 `#09090b` (zinc-like)
- Primary CTA: `#18181b`
- Shadows: `0 4px 20px -2px rgba(0,0,0,.05)` / hover `0 10px 30px -4px rgba(0,0,0,.08)`
- Cards: `rounded-2xl`, border `#e4e4e7`
- Palette modal: `#1c1c1e` surface

# Barcode Generator

Tool id: `barcode-generator`

Generate CODE128, CODE39, EAN, UPC, and related linear barcodes as PNG in the browser via JsBarcode.

## Develop

1. Implement / adjust logic in `run` inside `index.ts`
2. Adjust UI in `ui.svelte`
3. Expand tests under `tests/tools/barcode-generator.test.ts`

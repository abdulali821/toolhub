# Divider Maker

Tool id: `image-divider`

Make a wide repeating icon strip (Carrd / blog / profile divider) in the browser.

- Upload 1–8 sprites
- Patterns: repeat, alternate, sequence, icon + dots, dots, dashes, tilted, Starbanner (line — ornament — line)
- Effects: still (PNG), or rainbow / scroll / bounce as independent switches (animated GIF)
- Size presets including thin strips that work well for GIFs

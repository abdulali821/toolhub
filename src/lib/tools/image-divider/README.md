# Divider Maker

Tool id: `image-divider`

Make a wide repeating icon strip (Carrd / blog / profile divider) in the browser.

- Upload 1–8 sprites
- Patterns: repeat, alternate, sequence, icon + dots, dots, dashes, tilted
- Motion: still (PNG), rainbow, scroll, bounce, or combo (animated GIF)
- Size presets including thin strips that work well for GIFs

# Favicon Generator

Tool id: `favicon-generator`

Build a complete favicon bundle in the browser — desktop ICO/PNGs, Apple touch icon, PWA +
maskable icons, `site.webmanifest`, and an HTML snippet — with live platform previews
(browser tabs, iOS home screen, Windows taskbar, Android launcher).

- Source: logo upload (incl. SVG) or 1–2 letter initials
- Per-platform margin / background controls
- ZIP download of all assets
